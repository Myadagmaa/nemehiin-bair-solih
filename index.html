Нэмэхийн чанараар тоон илэрхийллийг хэрхэн хялбарчлах вэ?

Олон тооны нийлбэрийг олохдоо **аравт эсвэл зуут бүтээх** хоёр тоог эхэлж олж нэмбэл бодолт маш хялбар бөгөөд хурдан болно! Үүний тулд нэмэхийн 2 үндсэн чанарыг ашигладаг:

1. Байр солих чанар

Нэмэгдэхүүнүүдийн байрыг солиход нийлбэр өөрчлөгдөхгүй:
$a + b = b + a$

Жишээ: $17 + 28 = 28 + 17 = 45$
2. Бүлэглэх чанар

Зэрэгцээ хоёр нэмэгдэхүүнийг тэдгээрийн нийлбэрээр сольж болно:
$(a + b) + c = a + (b + c)$

Жишээ: $(14 + 16) + 25 = 30 + 25 = 55$
